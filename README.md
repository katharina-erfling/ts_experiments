# 🔷 TS Experiments

Eine wachsende Sammlung von TypeScript-Übungen – entstanden beim Lernen im Rahmen der Frontend Developer Zertifizierung JavaScript.

🚧 Work in Progress  
Dieses Repo wächst mit – neue Experimente kommen regelmäßig dazu.

## 🧩 Experimente

| Projekt | Beschreibung | Themen |
|--------|-------------|--------|
| uebung1.ts | Typfehler erkennen & beheben | Typen-Deklaration, number, Funktionsparameter & Rückgabetypen |
| uebung2.ts | Optionale Felder im Interface | interface, optionale Properties (?), union type string \| undefined, Type Narrowing |
| uebung3.ts | Interfaces & wiederverwendbare Funktionen | interface als Vertrag, Methoden-Signaturen, implizite Interface-Erfüllung, Wiederverwendbarkeit durch Typisierung |
